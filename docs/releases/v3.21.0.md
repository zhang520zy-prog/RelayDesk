## RelayDesk v3.21.0

本版本为界面与交互的整体重构，并完成大规模死代码清理。

### 界面与布局

- 侧栏重构：移除账户信息块，工作区导航与「设置 / 关于」分区以分割线隔开；导航区在默认窗口尺寸下完整显示、不再滚动
- 新增「关于」页：版本信息、项目链接、检查更新（含发布日期与更新说明）、更新并重启；设置页中的更新区块已迁移至此
- 环境部署页：检测结果行改为固定列栅格，状态标签跨行对齐；CLI 与桌面端命名区分；异常工具显示原因与修复入口；正常项不再显示"查看指引"
- 模型中心：分组卡片替代平铺表格，支持组内模型下拉选择、使用中高亮
- 会话管理：详情区放宽、会话列表可折叠、消息复制按钮、标题悬浮提示
- 钱包：结账区重排（支付金额主数字醒目、移除重复金额项）；状态列不再被右缘裁切
- 设置页：外观 / 通用 / 数据诊断分区更清晰；"重新打开新手引导"正确跳转环境部署页

### 数据与功能

- 充值记录：在线支付订单与到账日志（type 1 充值、type 3 管理员入账、type 6 退款）合并去重展示
- 待支付订单增加支付时限：超过站点返回的 expires_at（或创建后 30 分钟）自动显示"已过期"
- 会话记录过滤 Codex/Claude 注入的开发者与系统脚手架消息，展示真实对话内容
- 首次登录与换账号登录默认进入环境部署页（按账号记忆），老账号进入模型中心
- 登录代理修复：HTTPS 代理自动转换为 http CONNECT 方案，SOCKS 统一 socks5h

### 工程

- 清理约 275 个遗留 cc-switch 死代码文件、106 个失效测试与未引用资源（约 -9.9 万行）
- 双主题文字对比度均满足 WCAG AA
