## RelayDesk v3.22.0

本版本聚焦首次使用合规、凭据管理与 AI 工具接入能力扩展。

### 合规与安全

- 首次接入账号前弹出《RelayDesk 应用使用与风险声明》：需滚动阅读至底部并勾选确认后方可继续；声明可在「关于」页随时重读
- Windows 环境检测不再弹出命令窗口：补齐全部探测类子进程的无窗口标志，环境页反复进入也不会闪窗

### 凭据管理

- 新增独立「接入凭据」导航页（侧栏直达）：为 CherryStudio、WorkBuddy 等仅需 Base URL + API Key 的客户端创建中转站令牌
- 凭据支持复制完整 Key、编辑名称/分组/有效期（永久/90/30/7 天）、启用/停用与吊销；完整 Key 仅按需获取，列表始终掩码展示

### AI 工具接入

- 环境部署页按厂商聚合：OpenAI Codex、Claude、Gemini、Grok 各为一组，CLI 与桌面端分列，有待办项自动展开
- 新增 Grok Build：检测（原生安装目录 + npm）、安装（官方 installer + npm 兜底）、写 `~/.grok/config.toml` 接入中转站
- 新增 Devin：检测与安装支持（走 Cognition 自家账号体系，不写中转站凭据）
- Codex 图像生成一键修复：自动安装 codex-image2-skill，并把已应用的中转站配置写入 `~/.env` 与系统用户环境变量（macOS launchctl / Windows setx）
- 应用目标页配置位置自动定位（手动覆盖 > 环境变量 > 已存在的备选目录 > 默认），并标注「自动检测/自定义」来源

### 模型路由与引导

- 分组到应用目标的推断改为模型名驱动：`claude-opus/sonnet/haiku` 落 Claude，`gemini` 落 Gemini，`grok/xai` 落 Grok，`gpt/o3` 落 Codex；无法识别的组落到全部已启用目标，不再误发单一客户端
- 首次登录改为三步主动引导：自动检测 → 一键补装缺失工具 → 选择同步目标；老用户可跳过，设置页可重开
- 可选桌面端未安装的状态标签由「需关注」改为更准确的「可选」

### 其他

- 更新提示集中到「关于」页：其他页面不再显示版本/更新横幅；带下载进度的"更新并重启"仍可用
- 发版前死代码清理：移除 73 个前端不可达文件与 28 个未用依赖

### 工程

- 后端遗留命令面盘点记录于 progress.md（76 条零前端调用命令与 relay apply 共享基础设施，留待专项拆除）
