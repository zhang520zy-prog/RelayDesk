# RelayDesk v3.24.1

## 修复

- **中转站"记住密码"真正生效**：部分 new-api 发行版对普通账号关闭 `GET /api/user/token`（403 权限不足），此前只能保存 15 分钟短 JWT——会话频繁掉线、保存的登录隔天失效。现在登录时同时保存 30 天 session cookie（网页版同款凭据），所有请求自动携带，30 天内一键免登恢复
- 恢复已保存登录时会再次尝试换取长效系统令牌，拿到即自动升级凭据
- 恢复被拒时写入诊断日志，便于排查

## 会话恢复

- "恢复会话"改为下拉菜单：可选择**在终端恢复**（运行 resume 命令）或**在桌面端打开**（拉起对应桌面应用），按会话实际可用的方式只显示有效项
