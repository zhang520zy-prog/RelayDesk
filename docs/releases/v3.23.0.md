## RelayDesk v3.23.0

本版本聚焦用量统计完整性、钱包收银台对齐站点结算，以及 Devin/SWE 系列归属识别。

### 用量统计

- 消费日志明细分页全量拉取：按站点实际返回页长收尾，支持每页 200 条与最多 60 页（约 1.2 万行），拉取超时放宽至 150 秒，30 天全量明细不再中途截断
- 明细查询窗口健壮化：聚合时间戳毫秒归一化、起点钳制到合法区间；带窗请求被拒时自动降级为全量日志匹配，明细列不再整批空白
- 日志字段兼容各 new-api 版本：行数组兼容 `items`/`logs`/`data`/`records`，分组兼容 `use_group`/`group`/`group_name`，Token 兼容 `input_tokens`/`output_tokens` 别名；缺 `id` 的行照常统计
- 同模型跨分组消费时显示日志量最多的主导组，分组列不再空白
- 计费日志与站点汇总存在口径差异（未计费/失败请求）的行如实标注，顶部文案同步澄清
- 模型对比表移除缓存读/写两列，末列更名「费用」并按三位小数显示；模型明细榜模型名完整换行展示，数值与占比放大填充

### 钱包充值

- 充值金额逐档请求站点真实报价，优惠徽标与「实付·省 X」与站点收银台逐分一致（不再依赖 `amount_options` 自带的 discount 字段）
- 结算面板移至右侧独立吸顶卡：金额区置顶、付款区贴底，与左侧表单底边对齐；兑换码通栏展示，自定义金额并入金额瓦片行
- 金额瓦片按内容定宽：无优惠的小额档更紧凑；支付宝图标替换为官方完整矢量标

### AI 工具接入

- Codex 图像生成修复状态检测修正：`skills/` 下任何 `codex-image*` 目录均视为已装；环境变量检测覆盖 `~/.env`、`~/.codex/.env`、shell rc 文件与 `launchctl` 进程环境，手动配置不再误报未修复
- 登录页「环境诊断与工具」提升为顶部醒目按钮，未登录也可直达
- 登录页工具列表更新为 Claude / ChatGPT / Gemini / Grok / Devin

### 模型路由

- SWE/Devin/Cognition 系列模型与分组识别归属 Devin：应用目标页新增 Devin 卡片（「仅部署」徽标 + 前往部署入口），分组路由与模型应用结果中标注 Devin 归属，不误投其他客户端

### 工程清理

- 删除约 190 行无引用 CSS 规则与废弃换算函数，清理 82 个旧版多语更新日志文件及本地过期构建产物
