# RelayDesk UI/UX 审视与升级记录

日期：2026-09-20。阶段记录，等待用户试用反馈；不是最终 Handoff。

## 设计依据与范围

使用 ui-ux-pro-max 的桌面可访问性、信息层级、图表与数据展示规则。首次设计系统检索偏向文档站，不采纳；收窄到 analytics dashboard 产品域后，采用可比较的数据面板方向。沿用 rd-*、青绿色品牌、现有 React/Recharts/Radix 组件，未引入依赖。保留登录、模型应用、重启确认、支付的既有安全边界。本轮集中升级公共桌面框架和用量统计，不声称完成所有页面重设计。

## 本轮已实现

| 部位 | 行为及状态 |
|---|---|
| 页头刷新 | 仅模型中心、应用目标和设置显示账户/模型/分组刷新。钱包、用量和部署使用自身操作。 |
| 导航 | 页面变化后焦点进入标题并回到内容顶部；提供跳转主内容链接；侧栏折叠状态跨重挂载保留。 |
| 非敏感偏好 | 仅保存侧栏宽度、统计区间、图表形式、指标、粒度；校验允许值；存储不可用时仍可在当前组件使用。 |
| 统计筛选 | 区间、模型、刷新和时间范围整合成独立面板。选中模型后概览、图表、明细一致。数据刷新后选中模型不存在时显示全部模型。 |
| 概览 | 三项核心指标，增强字号与数字对齐；缺失字段不作为 0 汇总。真实 0 保留。 |
| 图表 | 每次仅显示一种形式；按模型名称稳定映射主题色；时间刻度取实际桶边界；颜色有明暗令牌。 |
| 明细 | 默认总 Token 降序；列头可切换排序，未知值置后；aria-sort 状态；明确数字列右对齐；表格支持键盘进入滚动区域。 |
| 小窗口 | 筛选换行、图例单列、紧凑侧栏；移除明细强制 1120px 宽度和柱图高度截断。 |
| 双语 | zh/en 各 484 个键，键集合一致；统计区间日期随界面语言格式化。 |

## 续轮优化（2026-09-20）

### 实现

- 钱包“重新读取”“查询到账状态”同步读取余额、订单、充值信息和报价，查询中禁用重复操作。
- 当前支付反馈按 tradeNo/orderId 匹配。翻到历史其他页时仍查询第一页寻找本次订单；找不到不推断成功，显示无法确认状态。
- 已到账替换等待付款提示；余额更新成功后才显示“余额已更新”。余额读取失败仍显示上次余额并提示重试；不展示原始异常。
- 账户刷新复用 useRelaySession，保留会话代次检查并增加并发刷新保护。
- 模型中心搜索和分组提升到当前应用会话，离开/返回保留，登录会话变化后清空；不落本地存储。
- 充值金额组、支付方式组补齐可访问名称；新增订单状态卡使用现有 rd 令牌。

## 充值比例、模型撞色与页面层级（第四轮）

依据用户实测反馈进行结构调整：

1. 根因：brand.css 的 .rd-account-card > div / strong 等规则同时命中了侧栏卡与钱包充值卡，导致表单内部排列和文字比例异常。已将这些基础规则限定到侧栏。
2. 充值重排：选择区与结算区分开。选择金额使用3列网格，支付方式独立分组；结算摘要突出实付金额、主付款按钮，说明使用11–12px次要文本。宽窗口左右分区，1100px以下切换上下分区，740/760px附近进一步单列；不修改支付创建及确认逻辑。
3. 模型配色：原来名称哈希取余会发生碰撞。现对完整模型集合排序后统一分配，优先主题色，已使用颜色避让；超过8种扩展HSL色。同次页面挂载内保留刷新已有配色，过滤/指标/视图切换共用映射。颜色数量很多时不承诺无限感知可区分，完整名称、数值和占比仍作为辨识依据。
4. 数据面板：宽窗口图表+模型明细侧栏，窄窗口上下排列；Token核心指标有柔和强调背景，图例每个模型有独立色条、完整名称及数值。
5. 各页结构：钱包余额横向摘要，模型中心独立指标卡，宽窗口设置双列、应用目标三列卡片+通栏映射。保留小窗口纵向阅读顺序。

本轮文件：account/WalletPage.tsx、account/UsageCharts.tsx、account/account.css、design/brand.css、design/polish.css、design/tokens.css、locales/{zh,en}.json、tests/relaydesk/usageCharts.test.{ts,tsx}。

验证：TypeScript通过；完整前端148文件/1270项通过；生产构建通过；git diff --check通过。新增测试覆盖Sol/Luna/Terra等碰撞避让、模型顺序改变、增加模型保留已有颜色、24种模型、三种图表和筛选图例颜色一致。测试DOM没有真实图表尺寸，Recharts有尺寸警告，不等于真实截图验收。

视觉：隔离模拟900×600模型页面可访问性报告无横向溢出；进入钱包的操作被用户同时操作Chrome打断。没有取得本轮充值/图表新布局的有效截图，未完成像素验收，不以旧截图替代。当前开发服务会加载最新源代码供用户审阅。没有真实登录或支付请求。
